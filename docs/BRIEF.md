# Product brief

The original request that scoped this repository lives in git history on `main`. This project is a **second product** with a similar session loop to the Apple Watch target in [FreedivingTrainer](https://github.com/wlwanpan/FreedivingTrainer), not a second `targets/watch`.

Realistic on Connect IQ: one-second timer, large clock, vibration and tones, Garmin sensor heart rate, completion record, retry from watch storage.

Not available: automatic install, HealthKit workouts, guaranteed delivery while both apps are backgrounded.
